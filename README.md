# power-bi-projects-
A detailed trend analysis report of JIO HOTSTAR , this report analyses the current overview based on its content type. It has both an overview point of view and a detailed report of every content type. It uses IMDB rating as a comparison factor to understand the customer's current content preferences #description This dashboard contains three files :- raw data backup file in excel, Excel file that contains both cleaned data and an excel prelimnary dashboard, a power bi report that has two pages.
